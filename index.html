Five n8n workflows take a CV from application to decision, answer policy questions, and report their own failures. Everything on this page runs on the real workflows, not a demo.

Apply for a job

Recruitment 1 · Intake

Candidates apply with a PDF CV. The workflow checks the application before anything is stored, so bad files and repeat applications never reach the pipeline.

  1. 1
    ValidateOnly PDF files are accepted. If something is wrong, the form shows what to fix.
  2. 2
    Check for duplicatesApplying twice for the same position with the same email is rejected.
  3. 3
    Save and logThe CV goes to Google Drive and a new row is added to the applications sheet.

AI screening

Recruitment 2

This workflow runs in the background, so there is nothing to click. Within an hour of applying, a candidate has a score and a reply.

  1. 1
    Read new applicationsIt picks up every application in the sheet that has not been screened yet.
  2. 2
    Score each CVAn AI model reads the CV and gives it a score.
  3. 3
    Reply and recordThe candidate gets an invite, a borderline note or a decline, and the sheet row is updated with the score and status.
Runs on error and on schedule

Error handler

Recruitment 3

The safety net for the other workflows. When a run fails, it is recorded and someone is told, so nothing fails silently.

  1. 1
    Log the failureEach error is written as a row in the error log sheet.
  2. 2
    Send an alertAn alert email goes out as soon as a run fails.
  3. 3
    Digest and queue checkA daily digest summarises the errors, and a scheduled check confirms applications are still moving through the queue.

Ask HR

RAG + GPT

Ask a question about company policy. The assistant answers only from the policy documents and names the source. If the policies don't cover it, it points you to HR.
